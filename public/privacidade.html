Política de Privacidade

Esta política descreve como dados são tratados ao usar o Gerador de Recibos Online.

1. Dados informados no formulário

Os dados preenchidos no formulário de recibo são utilizados apenas para geração e visualização local do recibo no navegador do usuário.

2. Anúncios e consentimento

Recursos de anúncios de terceiros são carregados somente quando habilitados e após consentimento explícito, quando aplicável.

3. Compartilhamento de dados

Não compartilhamos dados sensíveis do formulário com provedores de anúncios de forma intencional.

4. Contato

Para solicitações relacionadas à privacidade, utilize a página de Contato.
